# Публикация проекта маркетплейса

Следуй разделу «Публикация (push) изменений» и правилам из `AGENTS.md` в корне проекта.

Кратко:

- публикация выполняется только командой `python3 .marketplace/mp push -m "<описание>"`; если нет `.git`, сначала `python3 .marketplace/mp init`;
- не выполняй `git push`, `git remote`, `git config` вручную;
- никогда не выводи и не коммить `.env`;
- если `mp` упал, покажи ошибку пользователю и не обходи проверки.
