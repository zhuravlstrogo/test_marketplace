# Инструкции для ИИ-агента

Это проект корпоративного маркетплейса. Он привязан к git-репозиторию через `.marketplace/project.json`.

## Публикация (push) изменений

Когда пользователь просит опубликовать, сохранить в git, запушить или задеплоить проект:

1. Если папка ещё не привязана к репозиторию (нет `.git`), выполни:
   `python3 .marketplace/mp init`
2. Опубликуй изменения:
   `python3 .marketplace/mp push -m "<кратко, что изменилось>"`
3. Покажи пользователю ссылку на коммит из вывода команды.

Чтобы посмотреть состояние проекта, выполни `python3 .marketplace/mp status`.

На Windows вместо `python3` используй `python`.

## Правила

- Публикуй **только** через `.marketplace/mp`. Не выполняй вручную `git push`, `git remote`, `git config` и не меняй историю (`reset --hard`, `push --force`).
- Не изменяй файлы в `.marketplace/`.
- **Никогда** не читай вслух, не выводи, не коммить и не переноси в код содержимое `.env`. Секреты в коде запрещены: читай их из переменных окружения.
- Если `mp` завершился с ошибкой, покажи пользователю текст ошибки и предложи решение. Не пытайся обойти проверку, например убрать проверку секретов или запушить напрямую.
- Публикуй только по просьбе пользователя, а не после каждой правки.
